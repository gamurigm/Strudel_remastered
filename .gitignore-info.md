# GitIgnore Configuration for Strudel

Este archivo `.gitignore` ha sido optimizado para el proyecto Strudel, un port de TidalCycles a JavaScript.

## Secciones principales:

### 🟢 Node.js / JavaScript
- `node_modules/` - Dependencies
- Archivos de log de package managers
- Lockfiles opcionales (se mantiene `pnpm-lock.yaml`)

### 🔨 Build Outputs
- `dist/`, `build/`, `out/` - Directorios de compilación
- `coverage/` - Reportes de cobertura de tests
- `.astro/` - Cache de Astro (usado en website)

### 🛠️ Bundlers & Dev Tools
- `.vite/`, `.cache/`, `.parcel-cache/` - Caches de bundlers
- `.esbuild/`, `.rollup.cache/` - Otros bundlers

### 💻 IDEs y Editores
- `.vscode/`, `.idea/` - Configuraciones de IDE
- Archivos temporales de editores

### 🖥️ Sistemas Operativos
- `.DS_Store` (macOS)
- `Thumbs.db` (Windows)
- Archivos de papelera y temporales

### 🔐 Environment & Config
- `.env*` - Variables de entorno
- Archivos de configuración local

### 🎵 Audio/Media Específico
- `*.tmp.wav`, `*.tmp.mp3` - Archivos temporales de audio
- `.audio-cache/` - Cache de procesamiento de audio

### 🎹 Proyecto Strudel Específico
- `Dirt-Samples`, `tidal-drum-machines` - Librerías externas grandes
- `mytunes.ts` - Archivos de usuario temporal
- Archivos específicos del proyecto

## Notas importantes:

1. **Samples**: Los samples están configurados para ser ignorados (no trackeados) para evitar archivos grandes en el repositorio. Solo se trackea el `samples/README.md`.

2. **Documentación**: Los archivos generados como `doc.json` son ignorados pero se regeneran automáticamente.

3. **Lockfiles**: Se mantiene `pnpm-lock.yaml` pero se ignoran `package-lock.json` y `yarn.lock`.

4. **Tauri**: Archivos de build de Rust/Tauri son ignorados.

## Mantenimiento:

Este `.gitignore` está organizado por secciones para facilitar el mantenimiento. Cuando agregues nuevas herramientas o frameworks, añade las entradas en la sección correspondiente.
